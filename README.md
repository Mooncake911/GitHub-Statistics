## Lines of Code Counter
This is a small Streamlit app which represent your GitHub statistics based on lines of code.\
This only works for files that are located in the main branch and in open repositories.

## Check your Repo for Secrets
You can also check repositories for secret leaks with [gitleaks](https://github.com/gitleaks/gitleaks).
